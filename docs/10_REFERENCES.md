# 10 — Official Technology References

These links are for implementation context and the in-app “Learn from NVIDIA” panel.

Check them again during implementation because documentation URLs and SDK versions can change.

## Omniverse Web SDK

- https://docs.omniverse.nvidia.com/ov-web-sdk/latest/index.html

Relevant concept:
Web SDK provides JavaScript/TypeScript tooling for browser experiences that stream Omniverse Kit applications via WebRTC.

MVP note:
Do not require this SDK. Explain it as the future path from the static demo to a true streamed Kit experience.

## PhysicsNeMo

- https://docs.nvidia.com/physicsnemo/latest/overview.html
- https://developer.nvidia.com/physicsnemo

Relevant concept:
Open-source Physics AI framework supporting model families such as neural operators, GNNs, transformers, PINNs and other physics-ML workflows, including CFD and engineering applications.

## Metropolis

- https://developer.nvidia.com/metropolis

Relevant concept:
Models, libraries and blueprints for video analytics AI agents/applications from edge to cloud.

## Video Search and Summarization (VSS)

- https://build.nvidia.com/nvidia/video-search-and-summarization/blueprintcard

Relevant concept:
Video search, summarization, interactive Q&A, alerts, event review and other agentic video-analysis workflows.

## Earth-2

- https://www.nvidia.com/en-us/high-performance-computing/earth-2/
- Regional equivalents may redirect.

Relevant concept:
Open weather/climate AI models, libraries and frameworks; can conceptually feed weather-driven engineering workflows.

## cuOpt

- https://docs.nvidia.com/cuopt/index.html

Relevant concept:
Open-source GPU-accelerated decision optimization engine.

## Isaac Sim

- https://developer.nvidia.com/isaac/sim/
- https://docs.isaacsim.omniverse.nvidia.com/

Relevant concept:
Open-source reference framework built on Omniverse libraries for robotics simulation, testing and synthetic data generation.

## NVIDIA NIM

- https://docs.nvidia.com/nim/

Relevant concept:
Optimized inference microservices for deploying AI models.

## OpenUSD

## Source policy

The implementation must:
- favor official documentation over blog summaries for technical labels;
- avoid unsupported performance claims;
- avoid promising product interoperability unless verified;
- store the date of the final documentation audit in the project README.
